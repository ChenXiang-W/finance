# 金盾智眼 · 小程序端（检测 + 对话）

原生微信小程序，只保留两个核心功能：**欺诈检测** 和 **与本地模型对话**。
与 Web 端共用同一个后端（`frontend/backend`，8000 端口），无需任何后端改动。

## 如何运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开开发者工具 → 导入项目 → 项目目录选择本文件夹（`financial-fraud-detector/miniprogram`）→ AppID 选「测试号」；
3. **关键一步**：工具右上角 → 详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**（否则无法请求本机 http 接口）；
4. 确保 PC 后端已启动（`启动_Vue3.py` 或 F5 全栈启动）；
5. 编译运行即可。

## 真机预览

手机和电脑连**同一个 WiFi**，然后：

1. 电脑上 `ipconfig` 查看局域网 IP（如 `192.168.1.100`）；
2. 修改 `utils/api.js` 里的 `BASE = 'http://192.168.1.100:8000'`；
3. 真机调试模式开启（开发者工具 → 真机调试），即可访问本机后端。

## 正式上线需要什么

- 已备案的 **HTTPS 域名**（小程序强制要求）+ 在小程序后台配置 request 合法域名；
- 后端部署到云服务器并配反向代理 + HTTPS 证书；
- 现有这个本地版仅用于开发调试与课程演示。

## 已知限制

- 对话用的是**本地 3B 模型**（未配 DeepSeek Key 时的离线引擎），质量有限；给后端配好 Key 后，把 `pages/index/index.js` 的检测请求带上 `engine: 'deepseek'` 即可切换；
- 小程序端当前为一次性返回（未接 SSE 流式），响应最长等待 5 分钟超时。
